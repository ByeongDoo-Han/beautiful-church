# 검증 기록

검증일: 2026-09-20. macOS, Node.js 22.23.2, Next.js 16.3.5, 설치된 Google Chrome의 독립 Playwright 프로필을 사용했습니다. 브라우저 테스트는 실제 서버와 실제 PPTX/PDF/MP3 파일을 사용합니다. 프로젝트 상위의 동기화 참조 파일은 수정하지 않았습니다.

브라우저 시나리오:

1. 실제 PPTX의 한글 슬라이드 렌더링, 다음 장 이동, 출력창 동기화, 화면 가리기, 양쪽 창 새로고침 및 닫기.
2. PDF.js canvas 전환, MP3 재생/일시정지/탐색/볼륨, 곡 변경 시 정지, 출력창에 audio 요소가 없음을 확인.
3. 실제 PPTX/PDF/MP3 파일 선택·저장·자료 연결·재실행 복구.
4. 예배 자료 다운로드 후 브라우저 네트워크를 차단하고 콘솔 새로고침, 새 출력창 생성, PPTX/PDF 표시, MP3 재생.
5. BroadcastChannel을 제거한 브라우저 환경에서 postMessage 동기화와 운영자 새로고침 후 재연결.
6. 팝업 차단, 화면 API 미지원, 화면 권한 거절에 대한 복구 안내. 이 실패 조건은 테스트에서 주입.
7. 전체화면 거절에 대한 직접 클릭 안내를 주입 검증. 이후 실제 Chrome Fullscreen API로 진입·상태 보고·해제 확인.
8. 비인증 클라우드 API 및 다른 Origin의 변경 요청 거절.
9. 손상된 PPTX 렌더링 오류 후 연결된 PDF로 전환하고, 새로고침 뒤 PDF 선택 복구.
10. 실제 콘솔 스크린샷 저장 및 주요 재생 제어의 화면 내 배치 확인.

- 서명 없는 원본 Blob 주소 접근이 차단됨을 확인했습니다.

- 최종 운영 배포: `dpl_FS9ox8xKJNMZeZakR9jf9gyaAqfA`.

재현 명령:


## 서버 파일 목록 추가 검증

- 관리자 로그인 후 콘솔 왼쪽 **서버 파일 목록**에서 실제 Blob 파일을 조회합니다. 이름·종류·용량·업로드 일시·예배 목록 등록 여부를 표시합니다.
- 파일은 100개 단위로 조회하고 **파일 더 불러오기**로 이어서 확인합니다. 새로고침, 빈 목록, 연결 오류 후 재시도, Escape 닫기와 이전 버튼 포커스 복구를 브라우저 테스트로 확인했습니다.
- API 단위 테스트는 인증 전 조회 차단, 등록되지 않은 파일 포함, 삭제된 파일 제외, 내부 예배 설정 파일 제외, 비공개 URL 미노출, cursor 검증을 확인합니다.
- 운영 사이트에 실제 MP3/PPTX를 업로드한 뒤 `/api/files` 결과와 화면의 파일명·실제 용량을 대조했습니다. 비인증 요청은 401입니다. 이후 새 브라우저에서 다운로드·해시 일치·오프라인 재생을 재검증하고 테스트 파일을 정리했습니다.
- 화면 확인 이미지: `artifacts/server-files.png`. 이 이미지에 표시된 파일은 검증용 샘플이며 서버에 남기지 않았습니다.

## 별도 확인이 필요한 범위

- 실제 원격 manifest의 동시 수정 경합과 webhook 재시도는 별도 장애 주입 검증이 필요합니다. 현재 자료 목록 충돌 로직은 단위/API 계약 테스트로 검증합니다.
- **실물 두 모니터 및 프로젝터**: 화면 선택 알고리즘은 테스트했고 창 생성/전체화면은 Chrome에서 실행했습니다. OS의 실제 창 좌표 배치와 프로젝터 해상도/배율, 오디오 라우팅은 현장에서 확인해야 합니다.
- Chrome 이외 브라우저, PowerPoint의 모든 특수 도형/폰트/애니메이션 호환성을 입증하지 않습니다. 실제 예배 자료로 리허설하고 PDF 대안을 준비하세요.
- 브라우저가 OS 수준에서 강제 종료되거나 IndexedDB 데이터를 퇴거하는 상황, 다중 PC의 동시 업로드 용량 예약, 로그인 공격에 대한 중앙 요청 제한은 이번 MVP 검증 범위 밖입니다.

## 현장 리허설 순서

1. 클라우드 환경변수 설정 → 로그인 → 파일 업로드/서버 저장 → 다른 브라우저에서 서버 자료 불러오기.
2. 두 모니터를 **확장 모드**로 연결 → 화면 권한 승인 → 출력창 위치/전체화면/ESC 동작 확인.
3. 실제 PPTX와 대체 PDF, 연결한 음원을 재생하며 볼륨·오디오 장치 확인.
4. 예배 자료 다운로드 완료 → 인터넷 차단 → 양쪽 창 재실행 → 슬라이드/음원 리허설.
5. 온라인 복귀 후 데이터 변경이 있으면 다시 자료 다운로드.
